# Roadmap

- **Phase 0** — format draft, verifier for two or three claim types,
  negative vectors that the verifier must reject.
- **Phase 1** — full tier A dossier for one curve. Validation:
  reproduce accepted values for secp256k1, P-256, Curve25519.
- **Phase 2** — batch run over the standard curve corpus. First public
  artefact is data, not code.
- **Phase 3** — RigidityAudit and the degrees-of-freedom metric.
- **Phase 4** — distributed farm with untrusted workers.
- **Phase 5** — append-only registry and the web frontend.
